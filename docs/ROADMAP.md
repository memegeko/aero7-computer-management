# Roadmap

## 0.1 testing milestone

- Three-pane management shell and persistent navigation.
- Read-only systemd, journal, Samba, account, performance, device, disk, and
  service views.
- Safe external launches and UDisks2 mount/unmount actions.
- Stable page IDs for Control Panel and Start-menu search integration.

## Later milestones

- Polkit-mediated service operations after an authorization review.
- Guided scheduled-task creation.
- Exportable event-log filters and performance reports.
- Carefully reviewed storage actions. Destructive partition editing will not
  be added until it has a dedicated safety design and test suite.
